# Effing project `real-estate`

Programmatic image and video creation with the `@effing/*` packages — see [`GUIDE.md`](./GUIDE.md) for setup and deployment.

## Listing Promo Effies

- `listing-promo-fancy` uses annies for richer animated photo, pill, and realtor-card sequences.
- `listing-promo-basic` only uses image layers plus Effie transitions/effects/motions, so it renders faster while keeping the same overall promo structure.
